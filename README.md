*🎬 CineMovies – Full Stack Movie Management Platform*

CineMovies est une application web full-stack permettant la gestion complète de films, utilisateurs, notes et avis, avec un dashboard interactif pour visualiser les statistiques.

Le projet a été développé avec une architecture scalable, en séparant clairement le frontend et le backend, et en respectant les bonnes pratiques de développement.

 *Fonctionnalités*

- CRUD pour utilisateurs et films

- Attribution de notes aux films

- Rédaction et consultation de reviews

- Dashboard interactif pour visualiser :

    - Nombre de films notés

    - Nombre de reviews écrites

    - Moyenne des notes par utilisateur

- Interface responsive inspirée de Netflix / IMDb
  
*Stack Technique* 
  
- Frontend

- React (Vite)

- React Router DOM

- TailwindCSS

- Axios

- Chart.js / react-chartjs-2

*Backend*

- Flask REST API

- SQLAlchemy

- Base de données relationnelle

*Installation*

  - Backend

  - Frontend

   Le frontend communique avec l’API backend via les endpoints REST définis.

*Utilisation*

1. Accéder à l’application via le navigateur (Vite)
2. Créer des utilisateurs et des films

3. Ajouter des reviews et notes

4. Consulter les statistiques dans le dashboard

 *Objectifs du projet*

- Appliquer une architecture frontend / backend propre

- Gérer le flux de données et les appels API

- Créer un dashboard interactif et des visualisations statistiques

- Développer une application full-stack moderne et scalable

*Liens*

- Backend : Flask REST API

- Base de données : SQLite / PostgreSQL (selon configuration)
